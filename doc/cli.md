# Command-line options

ABCA is controlled entirely from the command line.

The `--mode` option selects the operation to perform:

| Mode      | Description                                                                 |
| --------- | --------------------------------------------------------------------------- |
| `run`     | Run a simulation and save it as a binary file.                              |
| `render`  | Render a binary simulation as PNG images, an animated GIF, or an MP4 video. |
| `xml`     | Export a binary simulation to XML (for example for TrackMate).              |
| `analyze` | Analyze a binary simulation and export agent trajectories.                  |
| `info`    | Display information about a binary simulation.                              |

The remaining options configure the selected mode.

| Option                   |             Default | Description                                                                    |
| ------------------------ | ------------------: | ------------------------------------------------------------------------------ |
| `--mode`                 |               `run` | Execution mode (`run`, `render`, `xml`, `analyze`, `info`).                    |
| `--model`                |              `life` | Simulation model (plugin).                                                     |
| `--rows`                 |               `200` | Number of grid rows.                                                           |
| `--cols`                 |               `200` | Number of grid columns.                                                        |
| `--generations`          |               `100` | Number of simulated generations.                                               |
| `--seed`                 |                 `1` | Random seed.                                                                   |
| `--density`              |              `0.25` | Initial fraction of active cells.                                              |
| `--toroidal`             |             `false` | Use periodic (toroidal) boundary conditions.                                   |
| `--out`                  | `simulation.autbin` | Binary simulation output.                                                      |
| `--input`                |            *(none)* | Binary simulation input.                                                       |
| `--xml`                  |    `simulation.xml` | XML output file.                                                               |
| `--png`                  |            *(none)* | Output directory for PNG frames.                                               |
| `--gif`                  |            *(none)* | Animated GIF output.                                                           |
| `--mp4`                  |            *(none)* | MP4 video output.                                                              |
| `--fps`                  |                `30` | Animation frame rate.                                                          |
| `--every`                |                 `1` | Render one frame every *N* generations.                                        |
| `--cell-size`            |                 `3` | Cell size (pixels).                                                            |
| `--palette`              |         `grayscale` | Rendering palette.                                                             |
| `--palette-states`       |               `256` | Number of colours generated by the palette.                                    |
| `--render-root`          |            `output` | Root directory for rendered outputs.                                           |
| `--render-name`          |       *(timestamp)* | Name of the render directory. If omitted, a timestamp is used.                 |
| `--ffmpeg-log`           |              `true` | Save FFmpeg output to `ffmpeg.log`.                                            |
| `--no-ffmpeg-log`        |                   — | Disable FFmpeg logging.                                                        |
| `--background`           |            *(none)* | Background colour (name or `#RRGGBB`).                                         |
| `--skip-background`      |              `true` | Do not render cells with colour index 0.                                       |
| `--draw-background`      |                   — | Render cells with colour index 0.                                              |
| `--agents`               |                 `0` | Number of agents (agent-based models).                                         |
| `--csv`                  |  `trajectories.csv` | CSV output file for `analyze` mode.                                            |
| `--tracking-xml`         |            *(none)* | XML particle-tracking output for `analyze` mode.                               |
| `--list-models`          |             `false` | List all available models and exit.                                            |
| `--plugin-arg KEY=VALUE` |                   — | Pass a plugin-specific parameter. This option may be specified multiple times. |
