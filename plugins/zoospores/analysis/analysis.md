# Trajectory analysis


---

## Trajectory resampling

The utility `resample.sh` (together with `resample.py` and `resample.conf`)
resamples simulated ABCA trajectories to match the distribution of trajectory
lengths in an experimental dataset. Each output trajectory is generated by
randomly extracting a contiguous segment from a sufficiently long simulated
trajectory. The resulting XML files preserve the simulated trajectory dynamics
while reproducing the empirical distribution of trajectory lengths.

### Input

A configuration file (`resample.conf`) specifying the locations of the Python
interpreter, input/output directories, and empirical trajectory-length file.

### Output

For each input XML file, the script produces:

- a resampled XML trajectory file;
- a provenance table indicating the origin of every sampled trajectory segment;
- a CSV file listing the sampled trajectory lengths.

### Usage

```bash
./resample.sh
```

The Bash wrapper processes multiple XML files in parallel while limiting the
number of concurrent jobs.
