## Validating behavioural simulations

### Purpose

Compare experimentally reconstructed trajectories with an ensemble of
independent simulations. The script quantitatively evaluates the agreement
between experiments and simulations by comparing the distributions of local
and global trajectory descriptors. Rather than analysing individual
simulations, it summarizes the median behaviour and interquartile range across
independent simulation replicates.

### Input

- `python.conf` generated by `setup_python.sh`
- Validation configuration file
- Experimental trajectory-analysis directory
- Parent directory containing independent simulation analyses

### Output

The output directory contains:

- publication-ready comparison figures for each trajectory descriptor;
- CSV files containing the aggregated distributions used to generate the
  figures;
- `comparison_summary.csv`, summarising the main validation statistics;
- `comparison_metadata.csv`, recording the analysis parameters;
- `simulation_manifest.csv`, listing all simulation replicates included in the
  comparison.

### Usage

```bash
./validate_simulations.sh CONFIG_FILE
```

### Notes

- The Python interpreter is automatically read from `python.conf`.
- All validation parameters are defined in the configuration file.
- Simulation replicates are automatically detected from the parent directory.
- Distribution-based descriptors are summarized using the median and
  interquartile range across independent simulations.
- Mean squared displacement (MSD) and heading isotropy are compared using the
  same ensemble-based approach.
- The generated figures are intended for quantitative model validation and are
  suitable for direct inclusion in publications.
