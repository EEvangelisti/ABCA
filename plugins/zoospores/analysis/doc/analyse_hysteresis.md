# Analyse Hysteresis

## Configuration variables

| Variable | Description | Default |
|---|---|---|
| `METRICS_DIR` | Metrics directory. | `Required` |
| `HYSTERESIS_DIR` | Output directory. | `<METRICS_DIR>/fast_slow_hysteresis_sensitivity` |
| `HYSTERESIS_WIDTHS` | Comma-separated widths. | `0,5,10,15,20,30,40` |
| `OTSU_BINS` | Otsu bins. | `256` |
| `HISTOGRAM_BINS` | Histogram bins. | `50` |
| `DPI` | Figure resolution. | `300` |
