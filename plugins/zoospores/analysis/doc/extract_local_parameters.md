# Extract Local Parameters

## Configuration variables

| Variable | Description | Default |
|---|---|---|
| `METRICS_DIR` | Metrics directory. | `Required` |
| `LOCAL_PARAMETERS_DIR` | Output directory. | `<METRICS_DIR>/abca_rationale` |
| `FAST_SLOW_THRESHOLD` | Optional threshold. | `empty` |
| `HYSTERESIS_HALF_WIDTH` | Half-width. | `25` |
| `MAX_LAG_STEPS` | Maximum lag. | `25` |
| `QUANTILE_GRID_SIZE` | Quantile grid. | `1001` |
| `ACCEL_CAP_MULTIPLIER` | Acceleration cap. | `3` |
| `MICRONS_PER_CELL` | Scale. | `10` |
