# Plot Trajectory Overview

## Configuration variables

| Variable | Description | Default |
|---|---|---|
| `FILTERED_METRICS_DIR` | Filtered metrics. | `empty` |
| `COMPLETE_METRICS_DIR` | Complete metrics. | `empty` |
| `OVERVIEW_DIR` | Output directory. | `<primary>/trajectory_overview` |
| `ANGULAR_BINS` | Angular bins. | `36` |
| `MAX_TRACKS` | Maximum tracks. | `2000` |
| `LINE_WIDTH` | Line width. | `0.55` |
| `MAX_TRACKS_PER_DECILE` | Tracks per decile. | `500` |
| `DPI` | Figure resolution. | `300` |
