# Validate Simulations

## Configuration variables

| Variable | Description | Default |
|---|---|---|
| `EXPERIMENTAL_DIR` | Experimental directory. | `Required` |
| `SIMULATIONS_ROOT` | Simulation root. | `Required` |
| `OUTPUT_DIR` | Output directory. | `Required` |
| `SIMULATION_PATTERN` | Pattern. | `Required` |
| `DPI` | Figure resolution. | `300` |
| `BINS` | Histogram bins. | `50` |
| `UPPER_PERCENTILE` | Optional. | `empty` |
