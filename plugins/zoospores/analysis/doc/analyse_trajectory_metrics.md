# Analyse Trajectory Metrics

## Configuration variables

| Variable | Description | Default |
|---|---|---|
| `METRICS_DIR` | Metrics directory. | `Required` |
| `GROUPED_ANALYSIS_DIR` | Output directory. | `<METRICS_DIR>/grouped_analysis` |
| `DPI` | Figure resolution. | `300` |
| `STATE_SPEED_THRESHOLD` | Optional threshold. | `empty` |
| `BINS` | Histogram bins. | `50` |
| `COUPLING_BINS` | Coupling bins. | `20` |
| `SMOOTH_FRAC` | LOWESS fraction. | `0.20` |
