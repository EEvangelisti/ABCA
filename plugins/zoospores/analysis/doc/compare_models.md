# Compare Models

## Configuration variables

| Variable | Description | Default |
|---|---|---|
| `EXPERIMENTAL_ANALYSIS_DIR` | Experimental directory. | `Required` |
| `EMPIRICAL_ANALYSIS_TEMPLATE` | Empirical template. | `Required` |
| `HMM_ANALYSIS_TEMPLATE` | HMM template. | `Required` |
| `DISPLACEMENT_RELATIVE_PATH` | Relative displacement path. | `Required` |
| `MSD_RELATIVE_PATH` | Relative MSD path. | `Required` |
| `DISPLACEMENT_COLUMN` | Column. | `Required` |
| `LAG_COLUMN` | Column. | `Required` |
| `MSD_COLUMN` | Column. | `Required` |
| `SIMULATION_FROM` | First simulation. | `Required` |
| `SIMULATION_TO` | Last simulation. | `Required` |
| `CI_LEVEL` | Confidence interval. | `Required` |
| `OUTPUT_DIR` | Output directory. | `Required` |
| `OUTPUT_PREFIX` | Output prefix. | `Required` |
| `LOG_FILENAME` | Log file. | `Required` |
| `SIMULATION_ID_COLUMN` | Simulation id. | `simulation_id` |
| `DELIMITER` | Delimiter. | `,` |
| `ALLOW_MISSING_SIMULATIONS` | Allow missing. | `false` |
