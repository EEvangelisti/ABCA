## Extracting empirical local parameters

### Purpose

Extract the empirical local parameters required by the zoospore ABCA model
from trajectory metrics. The script estimates the empirical FAST/SLOW Markov
chain, exports empirical quantile functions, fits the latent bivariate
Gaussian VAR(1) process governing speed and turning dynamics, derives
acceleration safeguards, and produces the parameter files required by the
ABCA simulation plugin.

### Input

- `python.conf` generated by `setup_python.sh`
- Analysis configuration file
- Directory containing `step_metrics.csv` and `track_metrics.csv`
- Optionally, `turn_metrics.csv` when explicit turning-angle measurements are
  available

### Output

The output directory contains:

- `abca_local_parameters.csv`, listing all scalar parameters used by the
  simulation;
- `abca_empirical_quantiles.csv`, containing the empirical inverse cumulative
  distribution functions used to sample speeds and turning angles;
- `abca_local_parameters.json`, providing the complete model specification in
  machine-readable form;
- `abca_state_assignments.csv`, recording the FAST/SLOW classification used
  during parameter estimation;
- `abca_parameter_rationale.txt`, summarising the extracted parameters and
  their biological interpretation.

### Usage

```bash
./extract_local_parameters.sh CONFIG_FILE
```

### Notes

- The Python interpreter is automatically read from `python.conf`.
- All analysis parameters are defined in the configuration file.
- When no FAST/SLOW threshold is specified, the script estimates one
  automatically from the empirical speed distribution.
- State assignment uses a symmetric hysteresis band whose half-width is
  controlled by `HYSTERESIS_HALF_WIDTH`.
- Empirical speed and turning-angle distributions are exported as inverse
  empirical cumulative distribution functions rather than fitted analytical
  distributions.
- The temporal dependence between speed and turning angle is represented by a
  stationary bivariate Gaussian VAR(1) process whose transition matrix,
  innovation covariance, and stationary covariance are exported directly for
  use by the ABCA plugin.
- Acceleration is **not** treated as an independent stochastic variable. It is
  derived from successive speeds and is used only to define an optional
  numerical safeguard.
- Global trajectory statistics are exported solely as validation targets and
  are never imposed as local behavioural rules.
