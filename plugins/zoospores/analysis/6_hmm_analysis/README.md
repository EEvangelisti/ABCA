## Fitting and interpreting hidden Markov models

### Purpose

Fit Gaussian hidden Markov models (HMMs) describing local zoospore
behaviour, compare competing numbers of hidden states, evaluate model quality
using both information-theoretic and structural criteria, and generate the
complete set of tables, figures, and parameter files required for biological
interpretation and HMM-based ABCA simulations.

### Input

- `python.conf` generated by `setup_python.sh`
- HMM configuration file
- Directory containing:
  - `step_metrics.csv` (or `step_metrics.tsv`)
  - `turn_metrics.csv` (or `turn_metrics.tsv`)

### Output

The output directory contains:

- the complete BIC table for all tested models;
- the best model for each tested number of hidden states;
- model-selection tables combining BIC and structural-connectivity metrics;
- transition matrices and transition graphs;
- decoded state statistics in biological units;
- state occupancy and sojourn-duration tables;
- representative trajectories coloured by decoded HMM state;
- empirical state-specific quantile tables suitable for the ABCA HMM plugin;
- serialized HMM models and the associated feature scaler;
- publication-quality figures summarising model selection and biological
  interpretation.

Each tested number of hidden states also receives its own subdirectory
containing all model-specific outputs.

### Usage

```bash
./fit_hidden_markov_models.sh CONFIG_FILE
```

### Notes

- The Python interpreter is automatically read from `python.conf`.
- All HMM parameters are defined in the configuration file.
- Several random initializations are fitted independently for each number of
  hidden states, and the model with the lowest Bayesian Information Criterion
  (BIC) is retained.
- Model selection is reported using two complementary criteria:
  - the global minimum BIC;
  - the lowest-BIC model satisfying predefined structural-connectivity
    criteria.
- Structural diagnostics evaluate transition-graph connectivity, state
  occupancy, posterior certainty, and the absence of isolated states. They are
  intended to complement, rather than replace, biological interpretation.
- Speed, turning angle, and acceleration are transformed before HMM fitting
  using robust monotonic transformations to improve Gaussian modelling.
- Exported state-specific empirical quantile tables can be used directly by
  the ABCA HMM simulation plugin.
- By default, decoded observation tables are written only for the BIC-selected
  model and the structurally recommended model, avoiding several very large
  redundant files. This behaviour can be changed by setting
  `WRITE_DECODED_ALL=1` in the configuration file.
