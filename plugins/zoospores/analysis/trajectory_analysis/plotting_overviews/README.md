## Generating the trajectory overview

### Purpose

Generate overview figures and associated CSV files from extracted trajectory
metrics. The script summarises heading isotropy, centred trajectories,
trajectory-length distributions, trajectory-length deciles, and straightness
as a function of trajectory length.

### Input

- `python.conf` generated by `setup_python.sh`
- Plotting configuration file
- Directory containing the filtered `step_metrics.csv` and
  `track_metrics.csv` files
- Optionally, a directory containing the complete, unfiltered
  `track_metrics.csv` file

### Output

The output directory contains:

- heading-isotropy plot and summary tables;
- centred trajectories coloured by mean speed;
- a standalone mean-speed colour bar;
- trajectory-length distributions for the filtered dataset and, optionally,
  the complete dataset;
- centred-trajectory plots for each trajectory-length decile;
- straightness distributions and summary statistics for each
  trajectory-length decile;
- CSV files containing the data used to generate the figures.

### Usage

```bash
./plot_trajectory_overview.sh CONFIG_FILE
```

### A typical output

```bash
Generating trajectory overview...
  Filtered metrics: not specified
  Complete metrics: ../../output/metrics
  Primary metrics:  ../../output/metrics
  Output:           ../../output/trajectory_overview
  Python:           /home/user/setup/python_venv/bin/python
Figures and CSV files written to: ../../output/trajectory_overview
Trajectory overview completed.
```

### Notes

- The Python interpreter is automatically read from `python.conf`.
- Input, output, sampling, and figure parameters are defined in the
  configuration file.
- `MAX_TRACKS=0` displays all trajectories in the global centred-trajectory
  panel.
- `MAX_TRACKS_PER_DECILE=0` displays all trajectories in each decile panel.
- When `COMPLETE_METRICS_DIR` is defined, an additional trajectory-length
  distribution is generated for the complete, unfiltered dataset.
- Trajectories in the global panel are sampled across all ten
  trajectory-length deciles.
