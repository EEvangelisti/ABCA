## Analysing FAST/SLOW hysteresis sensitivity

### Purpose

Evaluate the robustness of FAST/SLOW state segmentation by applying increasing
hysteresis widths around an Otsu threshold estimated from the trajectory
speed distribution. The analysis quantifies how hysteresis affects state
occupancy, episode duration, episode length, transition probabilities, and
overall behavioural statistics.

### Input

- `python.conf` generated by `setup_python.sh`
- Analysis configuration file
- Directory containing the `step_metrics.csv` file generated by
  `extract_trajectory_metrics.sh`

### Output

The output directory contains:

- one subdirectory for each tested hysteresis half-width;
- FAST/SLOW episode tables;
- step-by-step state assignments;
- transition-probability tables;
- threshold and hysteresis-band visualisations;
- FAST and SLOW duration histograms;
- FAST and SLOW episode-length histograms;
- a summary table comparing all tested hysteresis widths;
- sensitivity plots showing the effect of hysteresis on the main behavioural
  statistics.

### Usage

```bash
./analyse_hysteresis.sh CONFIG_FILE
```

### Notes

- The Python interpreter is automatically read from `python.conf`.
- All analysis parameters are defined in the configuration file.
- A single Otsu threshold is estimated from the complete speed distribution
  and reused for every hysteresis width.
- Hysteresis widths correspond to **half-widths** around the Otsu threshold.
  For example, a value of `25` produces a hysteresis band extending from
  *threshold − 25* to *threshold + 25*.
- A hysteresis half-width of `0` reproduces the standard single-threshold
  FAST/SLOW segmentation.
