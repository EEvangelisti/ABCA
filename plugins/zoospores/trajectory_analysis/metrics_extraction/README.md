## Extracting trajectory metrics

### Purpose

Extract trajectory-level, step-level, and turn-level metrics from one or more
TrackMate-compatible or ABCA XML files. The script also computes mean squared
displacement (MSD), directional autocorrelation, and summary statistics, and
optionally generates a trajectory-length filtered dataset.

### Input

- `python.conf` generated by `setup_python.sh`
- Analysis configuration file
- One XML file or a directory containing XML trajectory files

### Output

The output directory contains:

- trajectory metrics (`track_metrics.csv`);
- step metrics (`step_metrics.csv`);
- turn metrics (`turn_metrics.csv`);
- mean squared displacement (`msd.csv`);
- directional autocorrelation (`direction_autocorrelation.csv`);
- XML source summary (`source_xml_summary.csv`);
- global dataset summary (`summary.csv`).

If trajectory-length filtering is enabled, an additional subdirectory is
created containing the filtered metrics together with filter diagnostics.

### Usage

```bash
./extract_trajectory_metrics.sh CONFIG_FILE
```

### A typical output

```bash
Extracting trajectory metrics...
  XML source: ../../tracks
  Output:     ../../output/metrics
  Python:     /home/user/setup/python_venv/bin/python
P_nicotianae_hmm_000042.xml: 2500 tracks
Complete metrics written to: ../../output/metrics
Trajectory metric extraction completed.
```

### Notes

- Both TrackMate and ABCA XML formats are supported.
- Input may consist of either a single XML file or a directory of XML files.
- The Python interpreter is automatically read from `python.conf`.
- Analysis parameters (frame interval, coordinate scale, filtering strategy,
  etc.) are defined in the configuration file.
