## Analysing trajectory metrics

### Purpose

Analyse the trajectory metrics generated by `extract_trajectory_metrics.sh` and
produce summary figures, descriptive statistics, and publication-ready plots
characterising zoospore motility.

### Input

- `python.conf` generated by `setup_python.sh`
- Analysis configuration file
- Directory containing the trajectory metrics generated by
  `extract_trajectory_metrics.sh`

### Output

The output directory contains:

- publication-ready figures;
- descriptive statistical summaries;
- trajectory and population-level analyses;
- additional tables and graphical outputs generated by the analysis script.

### Usage

```bash
./analyse_trajectory_metrics.sh CONFIG_FILE
```

### Notes

- The Python interpreter is automatically read from `python.conf`.
- All analysis parameters (input/output directories, figure resolution, etc.)
  are defined in the configuration file.
- The script is intended to analyse a complete trajectory-metric dataset
  generated by `extract_trajectory_metrics.sh`.
